## Selected AI Projects

### [EchoAgent](https://github.com/orchidp-creator/EchoAgent)
A LangGraph multi-agent workflow that transforms URLs or text into sourced audiobook lessons, using local Qwen2.5 models for research, planning, and content generation.

**Technologies:** Python, PyTorch, Qwen2.5, Hugging Face, LangGraph, MCP, DuckDuckGo, gTTS  
[GitHub Repository](https://github.com/orchidp-creator/EchoAgent) · [Live Website](https://1f26124613fd519eab.v2.appdeploy.ai/)

### [Minotaur](https://github.com/orchidp-creator/Minotaur)
An open-source framework for creating custom Audio Language Models with modular audio encoders, trainable projectors, language models, and parameter-efficient training and inference.

**Technologies:** Python, PyTorch, Hugging Face, PEFT/LoRA, Qwen2, Whisper, Torchaudio

### [Viper](https://github.com/orchidp-creator/Viper-Create-Your-Own-Mamba-Audio-LLM)
An open-source framework for building Mamba-based Audio Language Models using configurable audio encoders, automatic feature projection, instruction-style audio–text processing, and parameter-efficient adaptation.

**Technologies:** Python, PyTorch, Hugging Face, Mamba, PEFT/LoRA, Librosa

### [VIDSIM-FX](https://github.com/orchidp-creator/VIDSIM-FX)
An open-source framework for video similarity analysis and search using normalized video embeddings, pretrained encoders, multiple similarity metrics, and FAISS retrieval.

**Technologies:** Python, PyTorch, Hugging Face, VideoMAE, ViViT, TimeSformer, FAISS, OpenCV, Pytest
